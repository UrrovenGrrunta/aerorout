# AeroRoute

AeroRoute is a C# application designed to help users plan simple flight routes between airports using ICAO airport identifiers.

The application aims to provide a straightforward way to enter flight information, validate user input, and calculate basic flight route details.

## Features

Currently implemented:
- Departure and arrival ICAO code input.
- ICAO code format validation.
- Ground speed input in knots (KT).
- Ground speed validation.
- Basic route display.
- Error handling for invalid user input.

### Planned Features

- Airport database integration using CSV files.
- Airport lookup by ICAO code.
- Distance calculation between airports.
- Estimated flight time calculation.
- Saving flight route information to a file.

## Technologies

- **Language:** C#
- **Platform:** .NET
- **Interface:** Command-line interface (CLI)

## Getting Started

### Requirements

- .NET SDK
- A terminal or a C# development environment such as Visual Studio

### Running the Application

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/AeroRoute.git
```

Navigate to the project directory and run:

```bash
dotnet run
```
